# APEX-9
APEX-9 é um robô autônomo de alta velocidade para competições de Line Follower. Desenvolvido com STM32, 9 sensores de linha, encoders, IMU e sensores de distância, combina precisão, estabilidade e velocidade. O chassi e as rodas são produzidos em impressão 3D, com software modular e foco em evolução e desempenho.
